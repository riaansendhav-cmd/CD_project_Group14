INITIAL TERMINALS

First Sets Table

Analyze a grammar to compute FIRST sets.

FIRST(α) represents the set of terminal symbols that can begin any string derived from α. If α derives the empty string, then ε is contained within FIRST(α).
SENTENTIAL NEIGHBORS

Follow Sets Table

Analyze a grammar to compute FOLLOW sets.

FOLLOW(A) represents the set of terminal symbols that may appear immediately to the right of non-terminal A in any sentential form. The endmarker $ is always a member of FOLLOW for the start symbol.
